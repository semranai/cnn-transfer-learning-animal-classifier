# CNN Transfer Learning — Animal Classifier

This project applies **Transfer Learning** using **EfficientNet-B0** and **DenseNet121** to classify animal images.  
Developed as part of **CNN for Visual Recognition (420-A19-AS)** at *LaSalle College*.

---

## Project Overview
- Implemented two models: EfficientNet-B0 and SimpleCNN.
- Compared validation accuracy, F1 score, precision, and recall.
- Used PyTorch and trained on Google Colab.

---

## Tech Stack
- Python • PyTorch • torchvision • sklearn • matplotlib

---

## Results
| Model | Accuracy | F1 Score |
|--------|-----------|----------|
